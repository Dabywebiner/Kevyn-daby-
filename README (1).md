# Kevyn Daby — Personal Website

A responsive, static personal website built with HTML, CSS and vanilla JavaScript.

## Run locally
- Open `index.html` directly in a browser, or
- Serve this folder with a local development server.

## Before publishing
1. Replace the placeholder email `hello@kevyndaby.com` in `index.html` (search for the TODO comment).
2. Add any additional accomplishments and project details.
3. Add project links, screenshots and a real profile image if desired. To make a project card clickable, wrap it in an `<a href="...">` and add `<span class="project-arrow">↗</span>` back next to the title.
4. Review personal details (for example the "EST. 2007" label in the About section) and remove anything you do not want public.

## Editing your content
All text about you (email, about tabs, timeline, achievements, stats) lives in `data.js`. Add an achievement by adding one line to the `achievements` list; categories become filter buttons automatically.

## Files
- `index.html` — page content and structure
- `style.css` — dark visual theme, wool-inspired navigation, responsive layout and animations
- `data.js` — your personal content (edit this most)
- `script.js` — mobile navigation, scroll reveals, active navigation and progress indicator

No login, database or backend is required.
